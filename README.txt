# Интерактивная карта памятников Чаа-Хольского кожууна

В проекте 9 памятников. Могильник Куйлуг-Хем удалён.

## Файлы
- index.html — страница карты.
- style.css — оформление.
- map.js — данные памятников и логика карты.
- supabase-config.js — публичные параметры подключения Supabase.
- supabase-setup.sql — правила доступа и таблица фотогалереи.
- images/ — локальные изображения.

## Координаты
В map.js замените lat: 0 и lng: 0 у каждого памятника на реальные координаты.

## Общая фотогалерея
GitHub Pages не хранит загружаемые посетителями файлы. Для общей галереи используется Supabase.

1. Создайте проект Supabase на бесплатном плане.
2. В Storage создайте bucket `monument-photos` и включите Public bucket.
3. В Authentication создайте одну учётную запись администратора.
4. После создания администратора отключите публичную регистрацию новых пользователей (Disable signups).
5. В SQL Editor выполните содержимое `supabase-setup.sql`.
6. В настройках Supabase скопируйте Project URL и публичный anon/publishable key в `supabase-config.js`.
   Никогда не помещайте в этот файл service_role key или пароль.
7. Загрузите обновлённые файлы проекта на GitHub Pages.

После настройки на сайте появится кнопка «Добавить фото». Только вошедший администратор сможет загружать изображения; фотографии будут видны всем посетителям. Максимальный размер файла в интерфейсе — 5 МБ.

Бесплатный план Supabase включает 1 ГБ файлового хранилища и может приостанавливать проект после недели бездействия. Условия могут меняться; проверяйте актуальные лимиты на официальной странице тарифов.

## Deep-link
После заполнения координат ссылка `index.html#sume` откроет карточку памятника.

## OpenStreetMap
Для загрузки карты нужен интернет. Сохраняйте атрибуцию OpenStreetMap и соблюдайте правила использования тайлов.
